│ 1. CLASSIFICATION - "Will this vehicle fail?"                               │
│    • Logistic Regression, Random Forest, XGBoost, Gradient Boosting        │
│    • Output: Yes/No with 96% accuracy                                      │
│    • Metrics: Precision, Recall, F1-Score, AUC-ROC                         │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. REGRESSION - "How many maintenance hours needed?"                       │
│    • Linear, Ridge, Lasso, Gradient Boosting Regression                    │

│    • Metrics: R² Score (95.6%), MAE, RMSE                                  │
└─────────────────────────────────────────────────────────────────────────────┘

│    • Output: Survival probability curves, risk factors                      │
│    • Key: Median survival time, hazard ratios                              │
└─────────────────────────────────────────────────────────────────────────────┘

│    • Applications: Budget planning, seasonal patterns                       │
