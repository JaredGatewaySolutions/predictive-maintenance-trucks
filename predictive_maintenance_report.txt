MODEL COMPARISON
--------------------------------------------------------------------------------

Metrics Explained:
  • Precision: Of predicted failures, how many actually failed?
    → High precision = Few false alarms (critical for resource allocation)
  • Recall: Of actual failures, how many did we predict?
    → High recall = Don't miss critical failures (safety)
  • F1-Score: Balance between precision and recall
  • AUC-ROC: Overall model discrimination ability (0.5=random, 1.0=perfect)

2. WEIBULL ANALYSIS
--------------------------------------------------------------------------------
Purpose: Parametric model common in reliability engineering
Strength: Provides shape (β) and scale (λ) parameters
  • β < 1: Decreasing failure rate (early failures)
  • β = 1: Constant failure rate (random failures)
  • β > 1: Increasing failure rate (wear-out failures)

Weibull Parameters:
  - Shape (β): 311.684
  - Scale (λ): 1.022
  → Interpretation: Increasing failure rate (wear-out)

3. COX PROPORTIONAL HAZARDS MODEL

Purpose: Identify risk factors for failure
Strength: Shows which variables increase/decrease failure risk

Hazard Ratios (Risk Factors):

Interpretation Example:
